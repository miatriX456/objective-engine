# Objective Engine for SillyTavern (v1.5.0)

Кастомный движок целей и квестов для SillyTavern.

Расширение внедряет в системный промпт ИИ ролевую логику динамического сопротивления. ИИ самостоятельно оценивает качество отыгрыша, продвигает шкалу прогресса от 0% до 100% и выводит скрытую оценку ходов.

---

## Структура файлов

Папка расширения должна находиться по пути:
SillyTavern/public/scripts/extensions/third-party/objective-engine/

objective-engine/
├── manifest.json
├── index.js
├── style.css
└── README.md

---

## Возможности

* Динамическое поведение ИИ: Персонаж ведет себя строго соразмерно текущему проценту:
  - 0-30%: Активное сопротивление, холодность, защита границ.
  - 31-70%: Сомнения, эмоциональное напряжение, трещины в защите.
  - 71-99%: Готовность сдаться, уязвимость.
  - 100%: Полное достижение цели, капитуляция или выполнение условий.
* Строгая оценка: Процент не растет от пустой болтовни — ИИ требует веских аргументов, эмоционального воздействия, улик или шантажа.
* Скрытый парсинг: Тег оценки [OBJ_EVAL] вырезается из итогового текста сообщения персонажа и выводится в интерфейс плавающего виджета.
* Макросы SillyTavern: Все системные промпты поддерживают {{char}} и {{user}}.

## Встроенные Пресеты

1. Первый поцелуй: Физическая дистанция -> нарастающее влечение -> поцелуй.
2. Полная близость (Секс): Границы и одежда -> интимное напряжение -> физическая близость.
3. Признание в любви: Отрицание чувств -> эмоциональные вспышки -> искреннее признание.
4. Выведать тайну: Защита секретов -> оговорки -> полное раскрытие тайны.
5. Склонить к предательству: Верность фракции -> моральный конфликт -> переход на сторону пользователя.
6. Искреннее покаяние: Гордость и защита -> осознание вины -> прошение о прощении.
7. Эмоциональный слом: Скупой на эмоции фасад -> слёзы и срыв всех масок.
8. Капитуляция в бою: Яростное сопротивление -> утомление -> складывание оружия.
9. Кабальная сделка: Отказ от невыгодных условий -> уступки под давлением -> подписание договора.
10. Свой вариант (Кастом): Возможность задать собственную цель и промпт поведения для ИИ.

## Установка и использование

1. Скопируйте папку objective-engine в public/scripts/extensions/third-party/.
2. Перезагрузите SillyTavern или нажмите Reload Extensions в настройках.
3. Откройте панель Extensions (расширения), найдите Objective Engine.
4. Включите движок галочкой, выберите пресет или настройте кастомный промпт.
5. Задайте лимит ходов.
6. Нажмите "Сбросить и начать квест" (>_<).

Виджет отобразится в верхней части экрана. Его можно сворачивать кликом по кнопке свертывания.
